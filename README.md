# Neekunza Gallery

A high-performance modern web photo gallery and media showcase built with Next.js, Supabase, and Tailwind CSS.

## Status
This repository is currently in the initial setup and staging phase.

## Core Features
- Cloud-backed media storage and instant asset delivery via Supabase Storage
- High-fidelity grid, masonry, and full-screen lightbox viewing modes
- Responsive layout optimized for mobile, tablet, and desktop viewports
- Dynamic album organization and tag filtering
